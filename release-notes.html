Release Notes

Track what is new in GenCatalog across desktop and extension updates.

GenCatalog 5.15.7 + Extension 5.21

Published May 12, 2026
Latest

Limited Venice.ai Chat Support

GenCatalog can now save visible image and video generations from your Venice chats, including prompt and model details when Venice exposes them on the page.

This is designed for privacy-conscious creators who want a local archive path: save the work you care about into GenCatalog, then delete it from Venice when you want that extra peace of mind.

Chat-Only, With One Video Caveat

Venice support is limited to chats. Public feed capture and bulk import are not included in this release.

For videos, press play first so the save badge can attach to the rendered video.

GenCatalog 5.15.6 + Extension 5.20

Published May 10, 2026

Safer Midjourney Duplicate Cleanup

Remove duplicates now preserves all four Midjourney variants from the same generation instead of treating sibling variations as interchangeable.

Repeat Saves Still Clean Up Normally

If the same Midjourney variant is saved more than once, GenCatalog can still identify the repeat record and keep your catalog tidy.

GenCatalog 5.15.5 + Extension 5.20

Published May 8, 2026

Grok HD Badges Restored

The desktop catalog grid again shows HD badges on Grok videos when the saved file is HD or has 720p+ dimensions.

Collection Controls Are Clearer

Collections now have visible controls for the common cleanup actions: removing an item from the current collection and deleting a collection from the sidebar.

These actions only change collection membership. The original images and videos stay in your catalog.

Collection Views Refresh Cleanly

After removing an item from a collection, GenCatalog updates the filtered view, collection counts, and detail panel immediately so the library no longer feels stuck on stale collection state.

GenCatalog 5.15.3 + Extension 5.19

Published April 24, 2026
Previous

Grok HD Videos Are Easier to Spot

Grok videos saved in HD now get a subtle HD badge in your catalog, including older videos GenCatalog can identify from the file itself. It is easier to tell at a glance which clips are already the higher-quality version.

Upgrade Saved Grok Videos to HD

If GenCatalog finds saved Grok videos that still have an HD version available, the extension can offer to upgrade them instead of treating them as already done. Upgrade progress now appears in the popup while the work is running, so you are not left guessing what is happening.

Higgsfield Saves Stay Out of the Way

On Higgsfield public grids, the GenCatalog save badge now sits in the bottom-left corner so it does not compete with Higgsfield's own heart button.

GenCatalog 5.15.1 + Extension 5.18

Published April 24, 2026
Previous

Midjourney Scans Are Much Smarter About Duplicates

Midjourney can change filenames and CDN URLs behind the scenes, which made it too easy for the same image to look "new" again later. GenCatalog now keys Midjourney items to the stable job ID and image position instead, so scans are better at recognizing what you already saved — and what you intentionally deleted.

That means fewer repeat imports, cleaner scan results, and less time babysitting your library.

Save Badges That Stick Around

Grok and Midjourney both redraw parts of their pages as you browse, refresh, and jump between views. The extension is now better at keeping GenCatalog save badges attached through those changes instead of disappearing after the page quietly rebuilds itself.

Grok post pages also now handle still images more reliably, not just videos.

Cleaner Progress While You Sync

Scan and download progress now shows up right where you started the action, so it is easier to tell what GenCatalog is doing while a bulk job is running. Midjourney downloads also end with a clearer summary: saved, already in catalog, previously deleted, or failed.

No more staring at vague metadata text and wondering whether the job actually finished.

The Real GenCatalog Icon Is Back

Desktop builds now use the current GenCatalog stacked-card icon across macOS, Windows, and in-app branding.

GenCatalog 5.15.0 + Extension 5.17

Published April 23, 2026

Full-Resolution Drag and Drop

Dragging from the desktop detail view now hands off the catalog's full-resolution file instead of a rendered thumbnail. A new Settings toggle keeps full-resolution drag and drop on by default, and failures now report clearly instead of silently falling back to the wrong asset.

Prompt Copy, Right Where You Need It

The detail view now has a compact copy icon beside the prompt so you can reuse prompts without hunting through the interface or selecting long text by hand.

Midjourney and Higgsfield Capture Fixes

Midjourney saves now preserve liked items as a searchable liked tag, with better metadata recovery on likes pages. Higgsfield capture has been tightened so saved assets use the full-resolution media rather than thumbnails.

Release Pairing

Desktop app 5.15.0 ships with Chrome extension 5.17. Existing desktop installs update through the in-app updater; new downloads are available for macOS and Windows.

GenCatalog Extension 5.16

Published April 21, 2026

A Full Popup Refresh

The Chrome extension got a major visual refresh. The popup has been rebuilt around a cleaner shell with a stronger hierarchy: header, single banner slot, platform strip, streamlined action rail, recent saves feed, and lighter-weight save confirmations. It feels less like a debugging console and more like the control center for the platforms you actually use every day.

Settings Now Own Download Preferences

Download HD, Upscale videos, and Smart Sync have moved into Settings as persistent set-it-and-forget-it preferences. Once you choose them, they stay remembered across popup closes and browser restarts. The main popup is now focused on scanning, syncing, and recent activity instead of long-lived options cluttering the primary flow.

Platform-Specific Actions That Make Sense

Grok, Midjourney, Higgsfield, and Digen now each show the controls that matter for that platform instead of sharing one crowded popup layout. Scan and download flows are cleaner, counts are more trustworthy, and misleading fallback actions have been removed from the main path.

Better Save Feedback and Reliability

The extension now has richer trial-state messaging, cleaner banners, more reliable recents, save receipts, and stronger bulk-save behavior. Offline saves can queue locally instead of vanishing into a generic failure, and Midjourney/Higgsfield preserve original creation time more reliably during bulk import so sorting by created date stays trustworthy.

Extension-Only Release

This release bumps the Chrome extension to 5.16 only. The desktop app version is unchanged.

The long-running Grok favorites scan bug is fixed. Hidden items are now properly recognized during scan, so Scan Favorites and Download New Items reflect what's actually actionable instead of phantom duplicates. GenCatalog 5.14.2

Published April 19, 2026

A New Sidebar

The sidebar has been rebuilt from the top down. At the top, a hero block shows how many generations are in your catalog right now, how many you've added in the last 30 days, and a small sparkline of daily saves across that window. Below it, a source ratio bar breaks your library down by platform — Grok, Higgsfield, Midjourney, Digen — at a glance. Click any platform in the legend to toggle it on or off.

Filters are reorganized around how you actually use them. Type, source platform, sort, rating, and favorites sit up top. Everything else lives in a Refine further accordion that expands in place. Active filter counts show inline so you always know what's narrowing your grid.

Collections are now pinned at the bottom of the sidebar, always visible without scrolling.

Settings Screen

GenCatalog has a proper Settings screen for the first time. Open it from the gear icon in the sidebar or with ⌘,. Six tabs: General, Capture & Import, Library, Maintenance, License, and About. The maintenance tools previously scattered in the sidebar now have a proper home with descriptions, last-run timestamps, and a Run all option.

Source Images — A New Way to Slice Your Catalog

Every generation that started from a reference image — image-to-image, character refs, style refs, edits — is now a first-class thing in your catalog. Open Source Images under Refine further to find a Has source image toggle, a strip of your top five most-used source images with counts, and Show all sources for the full searchable list sorted by how many generations came from each.

On a typical catalog, this surfaces around 1,000 distinct source images across roughly 11,000 generations — a side of your work you couldn't see before.

Top Prompts

Find every variation you've made from the same prompt idea. Under Refine further, Top Prompts groups your generations by the opening of their prompt. Click a prompt to narrow the grid to every generation that used it. Sort by most used, most recent, or A→Z. Prompts are grouped by their first 80 characters, normalized — so all the variations you've made by tweaking the back half cluster together.

Better Source Image Thumbnails

Some source image tiles were rendering as empty squares — especially for Grok video-extension chains, where the captured reference was a video frame rather than an uploaded image. The app now falls back to the child generation's own frame when a source lacks one. The empty-tile count dropped from 21 to 2 on a typical catalog, and video-extension sources now display their parent video's first frame automatically.

Polish

A lot of small things got better. The old purple gradient accent has been replaced with a quieter slate throughout the app. Emoji icons have been swapped for a consistent inline icon set that reads clearly at every size. The macOS menu bar icon has been redrawn as a proper template icon that matches the app mark and sits naturally next to other tray icons. Extension popup has been retuned so icons and save badges don't look padded or double-tiled. Refine sidebar icons have been reworked to be more legible at small sizes. About screen copy has been rewritten in the app's current voice. Footer legibility has been improved — the compact meta chips in the sidebar footer now read cleanly at a glance.

Icon Refresh Across App and Extension

GenCatalog now uses the updated app icon across the desktop app, extension surfaces, and popup branding. Small surfaces have also been tuned so the icon reads more clearly at extension and toolbar sizes.

Extension Polish (5.12)

The extension popup icon framing has been cleaned up so the icon no longer looks padded inside a second tile. Hover behavior on save badges has also been refined to feel smoother and more intentional.

GenCatalog 5.0.3

Published March 11, 2026

Hidden Items

A new way to keep select items out of your main library without deleting them. Hover any grid item and click the eye icon to hide it. Hidden items are protected behind a PIN and live in their own private section in the sidebar. Click any hidden item to open it in the full detail view — all metadata, tags, notes, and downloads work normally. Press Escape to return to hidden view, press Escape again to return to your main library.

Rediscover

The Random button is now Rediscover. Same behavior — surfaces a random generation from your library — but the name better reflects what it actually does: pulling up something you made months ago that you had completely forgotten about. A different kind of inspiration.

Shift-Select

Multi-select now supports range selection. In select mode, click one item to anchor it, then Shift+click another to select everything between them. Use Shift+Arrow keys to extend selection one item at a time.
