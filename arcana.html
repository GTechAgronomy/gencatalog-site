Why Arcana Needs a Library

Fast production tools create retrieval problems.

Arcana is built for serious creative iteration. That speed is powerful, but it also means useful generations can disappear into large project histories, browser sessions, and generic downloads.

  • Media can outlive the prompt that created it
  • Project context is easy to lose outside Arcana
  • Strong variations become difficult to compare later
  • Studio workflows need searchable metadata, not just files

GenCatalog gives Arcana output a durable local retrieval layer: search, filters, tags, notes, collections, and source-aware metadata.

Arcana FAQ

Questions that come up in real Arcana workflows.

Does GenCatalog support Arcana Labs?

Yes. GenCatalog includes native Arcana Labs support so Arcana generations can be saved and organized as Arcana items inside the local catalog.

Does GenCatalog save Arcana prompts?

Yes. GenCatalog preserves prompt text and negative prompt data when available, along with related metadata such as model details, settings, prompt IDs, and generation IDs.

Can I open a saved item back in Arcana?

When the source link is available, GenCatalog stores an Open in Arcana link so you can jump back to the original generation or project context.

Does Arcana content stay local?

Yes. GenCatalog stores the catalog, media, prompts, notes, tags, and metadata locally on your machine or the storage location you choose.

Is this useful for studio workflows?

Yes. Arcana support was designed around high-volume creative workflows where project context, prompt history, metadata, and source links matter as much as the final media file.
